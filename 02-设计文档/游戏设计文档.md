# 俄罗斯方块 Tetris - 游戏设计文档

> 版本: v1.0  |  日期: 2026-09-05  |  开发: 苏绍彰

## 一、项目概述

基于 Python + Pygame 开发的经典俄罗斯方块游戏，配套完整软件测试体系。采用"核心逻辑层与渲染层解耦"架构，核心逻辑不依赖任何图形库，可在无头环境由 Pytest 直接驱动，实现高覆盖率自动化测试。

## 二、技术选型

| 模块 | 技术                  | 说明           |
| -- | ------------------- | ------------ |
| 语言 | Python 3.9+         | 简历技能匹配       |
| 渲染 | Pygame 2.x          | 2D 绘制、输入、主循环 |

| 缺陷 | 禅道                  | 缺陷生命周期管理     |

## 五、核心算法

### 5.1 旋转

相对坐标顺时针 90°：`(x, y) → (y, -x)`，再归一化到非负坐标。O 方块不旋转。

### 5.2 Wall-kick

旋转后若碰撞，依次尝试 x 偏移 `0, -1, +1, -2, +2`，取首个合法位置。

### 5.3 消行

遍历棋盘，移除全满行，顶部补空行。返回消除行数用于计分。

### 5.4 7-bag 随机

每 7 个方块为一袋，内含全部 7 种并随机打乱，避免长时间不出某方块。
