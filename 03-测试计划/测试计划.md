# 俄罗斯方块 Tetris - 测试计划

> 版本: v1.0  |  日期: 2026-09-05  |  测试: 苏绍彰

## 一、项目概述

针对"俄罗斯方块 v1.0"开展功能、单元、性能、兼容性测试，验证满足设计文档 FR-01~~FR-22、NFR-01~~NFR-05 全部需求。

## 二、测试范围

### 2.1 范围内

| 模块               | 测试类型                       |
| ---------------- | -------------------------- |
| tetris\_core.py  | 单元测试（Piece/Bag/Tetris 全方法） |
| 方块生成与 7-bag      | 功能测试                       |
| 移动与旋转            | 功能测试（含 wall-kick）          |
| 碰撞与锁定            | 功能测试                       |
| 消行与计分            | 功能测试（1/2/3/4 行、combo）      |
| 等级与速度            | 功能测试                       |
| 游戏结束 TOPOUT      | 功能测试                       |
| 幽灵方块             | 功能测试                       |
| 状态机（准备/运行/暂停/结束） | 功能测试                       |
| 最高分持久化           | 功能测试                       |
| 帧率/内存            | 性能测试                       |
| 多 Python 版本      | 兼容性测试                      |

### 2.2 范围外

- Pygame 库自身缺陷

- 音效（本版本无音效）

## 三、测试策略

| 类型   | 方法                 | 工具                         |
| ---- | ------------------ | -------------------------- |
| 单元测试 | 白盒，语句+分支覆盖         | Pytest + coverage          |
| 功能测试 | 黑盒，等价类/边界值/场景法/判定表 | 人工 + 自动化                   |
| 性能测试 | 帧率/内存采样            | Pygame clock + tracemalloc |
| 兼容性  | 多环境运行验证            | Python 3.9/3.10/3.11       |

### 缺陷等级

| 级别 | 说明               |
| -- | ---------------- |
| P0 | 无法启动/崩溃/方块无法下落   |
| P1 | 旋转/消行/计分等核心功能异常  |
| P2 | 非核心功能异常（幽灵方块、预览） |
| P3 | 体验/UI 问题         |

## 四、进度

需求评审 → 计划 → 用例设计 → 单元测试 → 功能测试 → 性能测试 → 回归 → 总结

## 五、测试环境

| 项      | 配置              |
| ------ | --------------- |
| OS     | Windows 11      |
| Python | 3.10.11 / 3.9.7 |
| Pygame | 2.5.0           |

## 六、准出标准

- 用例执行率 100%

- P0/P1 缺陷修复率 100%

- P2 修复率 >= 90%

- 核心逻辑覆盖率 >= 90%

- 60FPS 稳定

- 三环境兼容通过

## 七、风险

| 风险                    | 应对              |
| --------------------- | --------------- |
| Pygame UI 无法在 CLI 跑单测 | UI 走人工测试，逻辑层全单测 |
| 7-bag 随机性致用例不稳定       | 固定 seed 复现      |
| 旋转 + wall-kick 组合多    | 用判定表覆盖关键组合      |
