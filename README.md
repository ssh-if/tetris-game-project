# 俄罗斯方块 Tetris - 开发与测试项目

> 应届软件测试工程师项目作品  |  开发 + 测试: 苏绍彰  |  2026-09

## 项目简介

基于 Python + Pygame 的经典俄罗斯方块游戏，配套完整软件测试体系。核心逻辑层与渲染层解耦，可在无头环境由 Pytest 直接驱动，核心逻辑覆盖率 93%。

## 快速开始

### 运行游戏

```bash
pip install pygame
cd 01-游戏源码
python tetris_game.py
```

操作：← → 移动  ↓ 软降  ↑/X 旋转  空格 硬降  P 暂停  R 重启  Esc 退出。

### 运行测试

```bash
cd 05-自动化测试
pip install pytest pytest-cov
pytest --cov=../01-游戏源码 --cov-report=term-missing
```

或双击 `run_test.bat`。
