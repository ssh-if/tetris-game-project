# 俄罗斯方块 Tetris

经典俄罗斯方块游戏，基于 Python + Pygame 开发。

## 游戏特色

- 🎮 **7 种标准方块**：I、O、T、S、Z、J、L
- 🔄 **旋转系统**：支持顺时针旋转 + wall-kick 踢墙（贴墙旋转自动偏移）
- 🧱 **4 档消行**：单消 / 双消 / 三消 / Tetris（一次消 4 行）
- 🎲 **7-bag 随机算法**：每 7 个方块包含全部 7 种，避免长时间不出某方块
- 👻 **幽灵方块**：半透明预览方块落点
- ⏩ **等级提速**：每消 10 行升 1 级，下落速度递增
- 🏆 **最高分持久化**：本地保存历史最高分
- 📊 **计分系统**：消行得分 × 等级 + combo 连击加分 + 硬降加分

## 安装运行

### 环境要求
- Python 3.9 及以上
- Windows / macOS / Linux

### 步骤

```bash
# 1. 安装 pygame
pip install pygame

# 2. 进入源码目录
cd 01-游戏源码

# 3. 运行游戏
python tetris_game.py
```

## 操作说明

| 按键 | 功能 |
|------|------|
| ← / A | 左移 |
| → / D | 右移 |
| ↓ / S | 软降（加速下落） |
| ↑ / X / W | 顺时针旋转 |
| 空格 | 硬降（直接落底） |
| P | 暂停 / 继续 |
| R | 重新开始 |
| Esc | 退出 |

## 计分规则

| 操作 | 得分 |
|------|------|
| 消 1 行 | 100 × 等级 |
| 消 2 行 | 300 × 等级 |
| 消 3 行 | 500 × 等级 |
| 消 4 行（Tetris） | 800 × 等级 |
| 硬降 | 每格 +2 分 |
| 连击（combo） | 50 × combo 数 × 等级 |

## 项目结构

```
俄罗斯方块/
├── 01-游戏源码/
│   ├── tetris_core.py    # 核心逻辑层（方块、碰撞、消行、计分，无图形依赖）
│   └── tetris_game.py    # 渲染层（Pygame 绘制、输入处理、主循环）
└── 02-设计文档/
    └── 游戏设计文档.md    # 需求与设计说明
```

核心逻辑层与渲染层解耦，`tetris_core.py` 不依赖任何图形库，便于后续扩展与维护。
